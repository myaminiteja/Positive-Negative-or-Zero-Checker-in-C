Positive, Negative or Zero Checker in C

A simple C program that checks whether a given number is positive, negative, or zero.

Project Structure
positive-negative-zero/
├── positive_negative_zero.c
├── README.md
├── output.txt
└── .gitignore

Features
Accepts an integer from the user.
Checks whether the number is positive.
Checks whether the number is negative.
Identifies zero.
Simple and beginner-friendly C program.
Requirements
C compiler such as GCC
Code editor or IDE
Git (optional, for uploading to GitHub)
How to Compile

Open the terminal inside the project folder and run:

gcc positive_negative_zero.c -o positive_negative_zero

How to Run
Windows
positive_negative_zero.exe

Linux/macOS
./positive_negative_zero

Sample Input
Enter a number: 25
